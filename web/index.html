    为什么本地解析有时会提示需要登录态？
    抖音 / TikTok 的 Web 端详情接口现在带 Argus 签名 + 验证码网关，匿名请求会被拦。
    解决办法二选一：
    
① 启动时带上你自己的 Cookie：python -m nodl serve --cookie-file cookie.txt
    （在浏览器 F12 → Application → Cookies 里复制 ttwid / msToken / sessionid 即可）
    
② 装 Playwright，用真实浏览器去解析：pip install playwright && playwright install chromium，然后 --browser
